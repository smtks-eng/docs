Manage your AI agent's skills through two types of tools: predefined tools that come built-in with the platform, and custom tools that you can create to extend your agent's functionality.

<Tabs>
  <Tab title="Tools (Predefined)">
    The **Tools (Predefined)** tab allows you to enable or disable built-in capabilities that your AI agent can use during conversations. Each tool represents a predefined function—such as answering FAQs, sending files, or escalating to a human agent—that can be toggled on or off depending on your business needs.  

    When a tool is enabled, additional configuration may be required before the agent can use it successfully. Some tools also depend on the **type of channel** where the end user is interacting (e.g., WhatsApp, Zendesk, Freshchat).  

    ---

    ## How to Enable or Disable a Tool

    1. Navigate to **AI Agent > Design > Skills** in the left menu.  
    2. Under **Tools (Predefined)**, locate the tool you want to manage.  
    3. Use the **toggle switch** to turn the tool on or off.  
    4. If the tool requires configuration, click **Configuration**, complete the required setup, and save your changes.  
    5. Check that the tool is supported by the **channels** your agent is connected to.  

    ---

    ## Available Predefined Tools

    ### **Send Files**  
    - **Description:** Allows the agent to send files directly to the user during a conversation.  
    - **Default:** Always enabled.  
    - **Configuration:** No setup required.  

    ---

    ### **Answer FAQs**  
    - **Description:** Enables the agent to respond to frequently asked questions about your product or service.  
    - **Default:** Always enabled.  
    - **Configuration:** No setup required. You can manage and update FAQs in the **Knowledge** section of the agent.  

    ---

    ### **Collect Information**  
    - **Description:** Enables the agent to collect, verify, and store user information (e.g., name, email, phone number) for lead generation or service requests.  
    - **Toggle:** Off by default.  
    - **Configuration:** Define the fields you want the agent to collect and where the data should be stored.  

    <Note>  
    This tool is **so important** that once enabled, it activates a dedicated **Collect Information tab** in the Skills section. From there, you can create, edit, and manage information collection configurations in detail.  
    </Note>  

    <Accordion title="How to Configure Collect Information">  
    1. Go to **AI Agent > Design > Skills > Collect Information**.  
    2. Click **New Configuration** to start.  
    3. Enter a **Name** for your configuration (e.g., `registro_interesados`).  
    4. Add any **Special Instructions** to guide the agent during information collection.  
    5. Add one or more **Fields** — each with a name, type, description, and validation rules.  
    6. Click **Save** to activate the configuration.  
    </Accordion>  

    ---

    ### **Send WhatsApp Flows**  
    - **Description:** Allows the agent to send interactive WhatsApp Flows (structured forms, surveys, booking flows, etc.) to users on the WhatsApp channel.  
    - **Toggle:** Off by default.  
    - **Channel requirement:** Requires a connected Meta WhatsApp channel.  
    - **Configuration:** Select which Flows to link, define when the agent should trigger each one, and choose the approved template to use.  

    <Accordion title="How to Configure WhatsApp Flows">

    When you open the configuration panel for the **Send WhatsApp Flows** tool, the platform loads the WhatsApp Flows and message templates available in your connected WhatsApp Business Account (WABA).

    #### Linking a Flow

    1. Each available Flow is listed with its **name**, **ID**, and current **status** (Published, Draft, Deprecated, etc.).  
    2. Use the **toggle** next to a Flow to link or unlink it.  
    3. You can search Flows by name or ID using the search bar.  
    4. The counter at the top-right shows how many Flows are currently linked (e.g., *1/3 linked*).

    #### Configuring a linked Flow

    Once a Flow is linked, an expandable configuration section appears with the following fields:

    | Field | Required | Description |
    |---|---|---|
    | **When should the agent send this Flow?** | Yes | Describe the scenario in which the agent should trigger this Flow. For example: *"When the user asks to book an appointment and has already shared their name."* |
    | **Template** | Yes | Select (or type) the name of an approved WhatsApp message template that contains a FLOW button pointing to this Flow. |
    | **Language** | Yes | Select (or type) the exact Meta language code of the template (e.g., `en`, `es_MX`). Each language corresponds to a separate template on Meta's side — the code must match exactly. |
    | **What should the agent say after sending?** | No | Optional instructions for what the agent should tell the user right after the Flow is sent successfully. For example: *"Tell them you sent a form and to tap the button to open it."* Leave empty to use the default completion message. |

    <Note>
    The **"What should the agent say after sending?"** field only takes effect after the Flow has been sent successfully. The agent will never say this message on a turn where the Flow was not sent.
    </Note>

    <Tip>
    If your templates are loaded from Meta, you'll see dropdowns for **Template** and **Language**. If they cannot be fetched, you can type the values manually.
    </Tip>

    #### Flow statuses

    - **Published** Flows can be sent to users.  
    - **Draft** Flows must be published in WhatsApp Manager before they can be sent in production.  
    - Flows in other statuses (e.g., Deprecated, Blocked) cannot be sent.

    #### Orphaned use cases

    If a linked Flow is deleted from your WABA, a warning banner appears listing the orphaned use cases. You can remove them from the configuration or restore the Flow in WhatsApp Manager.

    </Accordion>

    ---

    ### **Escalate to Human**  
    - **Description:** Allows the agent to transfer the conversation to a human agent when it cannot resolve the issue.  
    - **Toggle:** Off by default.  
    - **Channel requirement:** Requires an integration with Freshchat or Zendesk.  
    - **Configuration:** Define escalation rules, target inboxes, and agent groups.  

    ---

    ### **HubSpot**  
    - **Description:** Enables the agent to collect and sync contact properties with HubSpot CRM.  
    - **Toggle:** Off by default.  
    - **Configuration:** Connect your HubSpot account, then declare which properties the agent should collect.  

  </Tab>

  <Tab title="Custom Tools">
    The **Custom Tools** tab lets you create your own tools to extend what the AI agent can do. Custom tools connect the agent to your internal APIs and systems, enabling it to perform actions like looking up order status, checking availability, or triggering workflows in your backend.

    ---

    ## How Custom Tools Work

    Each custom tool defines:
    - **What the tool does** — A natural-language description that helps the agent understand when and how to use the tool.  
    - **API endpoint** — The URL and method the agent calls when it decides to use the tool.  
    - **Parameters** — The inputs the agent needs to collect from the user before making the API call.  
    - **Headers & authentication** — Any API keys or tokens required to authenticate the request.  

    When a user's message matches the tool's described use case, the agent automatically collects the required parameters, makes the API call, and uses the response to continue the conversation.

    ---

    ## Creating a Custom Tool

    1. Go to **AI Agent > Design > Skills > Custom Tools**.  
    2. Click **New Tool**.  
    3. Fill in the tool name, description, API endpoint, method, headers, and parameters.  
    4. Test the tool using the built-in test panel.  
    5. Save and enable the tool.  

    <Tip>  
    Write clear, specific descriptions for your tools. The agent relies on the description to decide when to use each tool.  
    </Tip>
