Manage your AI agent's skills through two types of tools: predefined tools that come built-in with the platform, and custom tools that you can create to extend your agent's functionality.

<Tabs>
  <Tab title="Tools (Predefined)">
    The **Tools (Predefined)** tab allows you to enable or disable built-in capabilities that your AI agent can use during conversations. Each tool represents a predefined function—such as answering FAQs, sending files, or escalating to a human agent—that can be toggled on or off depending on your business needs.  

    When a tool is enabled, additional configuration may be required before the agent can use it successfully. Some tools also depend on the **type of channel** where the end user is interacting (e.g., WhatsApp, Zendesk, Freshchat).  

    ---

    ## How to Enable or Disable a Tool

    1. Navigate to **AI Agent > Design > Skills** in the left menu.  
    2. Under **Tools (Predefined)**, locate the tool you want to manage.  
    3. Use the **toggle switch** to turn the tool on or off.  
    4. If the tool requires configuration, click **Configuration**, complete the required setup, and save your changes.  
    5. Check that the tool is supported by the **channels** your agent is connected to.  

    ---

    ## Available Predefined Tools

    ### **Send Files**  
    - **Description:** Allows the agent to send files directly to the user during a conversation.  
    - **Default:** Always enabled.  
    - **Configuration:** No setup required.  

    ---

    ### **Answer FAQs**  
    - **Description:** Enables the agent to respond to frequently asked questions about your product or service.  
    - **Default:** Always enabled.  
    - **Configuration:** No setup required. You can manage and update FAQs in the **Knowledge** section of the agent.  

    ---

    ### **Collect Information**  
    - **Description:** Enables the agent to collect, verify, and store user information (e.g., name, email, phone number) for lead generation or service requests.  
    - **Toggle:** Off by default.  
    - **Configuration:** Define the fields you want the agent to collect and where the data should be stored.  

    <Note>  
    This tool is **so important** that once enabled, it activates a dedicated **Collect Information tab** in the Skills section. From there, you can create, edit, and manage information collection configurations in detail.  
    </Note>  

    <Accordion title="How to Configure Collect Information">  
    1. Go to **AI Agent > Design > Skills > Collect Information**.  
    2. Click **New Configuration** to start.  
    3. Enter a **Name** for your configuration (e.g., `registro_interesados`).  
    4. Add any **Special Instructions** to guide the agent's behavior.  
    5. Add the **fields** you want to collect (name, email, phone, etc.) with their types and extraction rules.  
    6. Assign the **channels** where this configuration should be active.  
    7. Click **Save**.  
    </Accordion>  

    ---

    ### **Escalate to Human Agent**  
    - **Description:** Lets the agent hand off the conversation to a live human agent when needed.  
    - **Toggle:** Off by default.  
    - **Configuration:** Requires a compatible integration (Freshchat or Zendesk) to be connected.  

    ---

    ### **WhatsApp Flows**  
    - **Description:** Enables the agent to trigger WhatsApp Flows — interactive, structured forms and screens built in Meta's Flow Builder — during a conversation on WhatsApp.  
    - **Toggle:** Off by default.  
    - **Channel support:** WhatsApp only.  
    - **Configuration:** Link each Flow to a compatible WhatsApp message template and select the template language.  

    <Note>
    Only templates whose **first button** is a **FLOW button** pointing to the selected Flow are shown in the template dropdown. This ensures the template you pick will actually deliver the correct Flow at runtime. If no compatible template exists for a Flow, the template and language fields will be disabled.
    </Note>

    <Accordion title="How to Configure WhatsApp Flows">
    1. Go to **AI Agent > Design > Skills** and enable **WhatsApp Flows**.  
    2. Click **Configuration** to open the Flows panel.  
    3. For each Flow listed, toggle it **on** to link it to the agent.  
    4. Select a **Template** from the dropdown — only templates compatible with that specific Flow are listed. A template is compatible when its first button is a FLOW-type button targeting the selected Flow and the template is approved by Meta.  
    5. Choose the **Language** for the selected template. If only one language exists, it is auto-filled.  
    6. Click **Save**.  

    <Warning>
    Templates with statuses **DEPRECATED** or **BLOCKED** cannot be used and their Flows will show a warning badge.
    </Warning>
    </Accordion>

  </Tab>

  <Tab title="Tools (Custom)">
    The **Tools (Custom)** tab lets you create your own tools by defining API integrations that your agent can call during conversations.  

    Custom tools extend your agent's functionality beyond the built-in capabilities. For example, you can create a tool that looks up order status from your backend, checks inventory, books appointments, or performs any action available through an API.  

    ---

    ## How to Create a Custom Tool

    1. Go to **AI Agent > Design > Skills > Tools (Custom)**.  
    2. Click **New Tool**.  
    3. Fill in the tool configuration:  
       - **Name** — A descriptive name for the tool.  
       - **Description** — What the tool does (this helps the AI decide when to use it).  
       - **API Endpoint** — The URL the tool will call.  
       - **Method** — GET, POST, PUT, DELETE, etc.  
       - **Headers** — Any required headers (e.g., Authorization).  
       - **Parameters** — Define the input parameters the agent needs to collect from the user.  
    4. Click **Save**.
