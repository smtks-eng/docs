## Conecta tu agente con usuarios reales

La página **Conecta** se organiza en dos pestañas:

- **Canales** — conecta y administra los canales donde tu agente habla con los usuarios.
- **Comportamiento de Mensajería** — configura cómo tu agente maneja los mensajes en cada canal conectado.

Este paso convierte tu agente de «configurado» a «en producción».

---

## Pestaña de Canales

La pestaña de Canales se organiza en tres bloques:

- **Canales** — publica tu agente en canales propios y externos (burbuja web, chat externo, WhatsApp y otros; en la interfaz algunos nombres pueden aparecer en inglés).
- **Integraciones** — conecta herramientas o servicios externos de tu operación.
- **API** — envía y recibe mensajes desde tus propios sistemas.

### Chat externo (salida más rápida)

El **chat externo** te da una URL compartible para lanzar en minutos (en consola puede mostrarse como *External chat*).

<Steps>
  <Step title="Ve a Conecta > Canales">
    Abre tu agente y entra a la página **Conecta**.
  </Step>
  <Step title="Abre el chat externo">
    Selecciona la tarjeta de chat externo / *External chat*.
  </Step>
  <Step title="Copia la URL pública">
    En la pestaña **Domain setup**, busca la tarjeta **Default URL** y haz clic en el botón de copiar para copiar el enlace generado.
  </Step>
  <Step title="Prueba como usuario final">
    Abre el enlace en una ventana privada y valida casos de uso reales.
  </Step>
</Steps>

<Tip>
  También puedes conectar un **dominio personalizado** para que los usuarios accedan a tu Chat Externo desde una URL de marca como `chat.ejemplo.com/ai-agent`. Consulta la página de [Chat Externo](/channels/es/web) para ver todos los detalles de la pestaña de configuración de dominio.
</Tip>

### Burbuja web (embebido en tu sitio)

Usa la **burbuja web** cuando quieras el agente dentro de tu propia web (en consola puede aparecer como *Web bubble* / *Bubble*).

<Steps>
  <Step title="Abre el canal de burbuja">
    En **Conecta > Canales**, abre la tarjeta de burbuja web.
  </Step>
  <Step title="Genera credenciales y fragmentos de código">
    La consola muestra el fragmento (*snippet*) y las claves para la integración.
  </Step>
  <Step title="Añade el fragmento al sitio">
    Pega el script donde tu equipo implementa el código web.
  </Step>
  <Step title="Personaliza la experiencia">
    Ajusta marca, botón de apertura y mensaje de bienvenida.
  </Step>
</Steps>

### Canales de Meta (WhatsApp, Messenger, Instagram)

La página de Conecta siempre muestra una sección de **Meta** con tres tarjetas de canal:

| Canal | Descripción |
|---|---|
| **WhatsApp** | Canal de WhatsApp Business vía Meta |
| **Messenger** | Canal de Facebook Messenger vía Meta |
| **Instagram** | Canal de mensajería de Instagram vía Meta |

Cada tarjeta muestra un botón **Conectar** que abre el flujo de configuración para ese canal específico. No necesitas configurar la integración de Meta primero — las tarjetas siempre están visibles para que puedas iniciar el proceso de conexión en cualquier momento.

Para un recorrido detallado de la configuración de WhatsApp, consulta la guía [Cómo integrar WhatsApp](/integration-guides/es/como-integrar-whatsapp).

### Login Externo

**Login Externo** te permite crear una página de login pública y personalizable que autentica a tus usuarios finales contra tu propio endpoint. Esto es útil cuando tu agente necesita verificar la identidad de un usuario o acceder a datos a nivel de cuenta.

La tarjeta se encuentra en la sección de Canales. Haz clic en **Gestionar** para abrir el constructor de Login Externo, donde puedes:

- Diseñar el formulario de login (campos, logo, descripción, color de fondo)
- Configurar tu endpoint de autenticación (URL, método, headers, payload)
- Configurar el cifrado para la respuesta de autenticación almacenada
- Activar o desactivar la página pública

Para más detalles, consulta la página dedicada de [Login Externo](/agent/es/login-externo).

### Integraciones

Debajo de las tarjetas de canal encontrarás la sección de **Integraciones**. Aquí es donde conectas tu agente a plataformas de terceros como **Freshchat** y **Zendesk**.

Cada tarjeta de integración muestra su estado actual:

| Estado | Significado |
|---|---|
| **Conectado** | La integración está activa y lista |
| **No conectado** | Necesita configuración |

Haz clic en la tarjeta para configurar la integración. Para guías paso a paso, consulta:

- [Cómo integrar Freshchat](/integration-guides/es/como-integrar-freshchat)
- [Cómo integrar Zendesk](/integration-guides/es/como-integrar-zendesk)

### API

La sección de **API** te da las credenciales e información de endpoint necesarias para integrar tu agente programáticamente. Úsala cuando quieras enviar y recibir mensajes desde tus propios sistemas backend.

## Pestaña de Comportamiento de Mensajería

La pestaña **Comportamiento de Mensajería** te permite controlar cómo tu agente procesa y responde a los mensajes en cada canal conectado. Las configuraciones incluyen:

- **Timing de respuesta** — configura retrasos o indicadores de escritura
- **Manejo de mensajes** — define cómo el agente trata diferentes tipos de mensajes
- **Comportamiento por canal** — aplica reglas que solo afectan ciertos canales

<Tip>
  Revisa el Comportamiento de Mensajería después de conectar un nuevo canal para asegurarte de que el estilo de respuesta del agente se ajuste a las convenciones de esa plataforma.
</Tip>
