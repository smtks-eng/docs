Administra las habilidades de tu agente de IA a través de dos tipos de herramientas: herramientas predefinidas que vienen integradas con la plataforma y herramientas personalizadas que puedes crear para extender la funcionalidad de tu agente.

<Tabs>
  <Tab title="Herramientas (Predefinidas)">
    La pestaña **Herramientas (Predefinidas)** te permite habilitar o deshabilitar capacidades integradas que tu agente de IA puede usar durante las conversaciones. Cada herramienta representa una función predefinida—como responder preguntas frecuentes, enviar archivos o escalar a un agente humano—que puede activarse o desactivarse según las necesidades de tu negocio.

    Cuando una herramienta está habilitada, puede requerir configuración adicional antes de que el agente pueda usarla exitosamente. Algunas herramientas también dependen del **tipo de canal** donde el usuario final está interactuando (por ejemplo, WhatsApp, Zendesk, Freshchat).

    ---

    ## Cómo Habilitar o Deshabilitar una Herramienta

    1. Navega a **Agente IA > Diseño > Habilidades** en el menú lateral.
    2. En **Herramientas (Predefinidas)**, localiza la herramienta que deseas gestionar.
    3. Usa el **interruptor** para activar o desactivar la herramienta.
    4. Si la herramienta requiere configuración, haz clic en **Configuración**, completa la configuración requerida y guarda los cambios.
    5. Verifica que la herramienta sea compatible con los **canales** a los que tu agente está conectado.

    ---

    ## Herramientas Predefinidas Disponibles

    ### **Enviar Archivos**
    - **Descripción:** Permite al agente enviar archivos directamente al usuario durante una conversación.
    - **Predeterminado:** Siempre habilitado.
    - **Configuración:** No requiere configuración.

    ---

    ### **Responder Preguntas Frecuentes**
    - **Descripción:** Permite al agente responder preguntas frecuentes sobre tu producto o servicio.
    - **Predeterminado:** Siempre habilitado.
    - **Configuración:** No requiere configuración. Puedes gestionar y actualizar las preguntas frecuentes en la sección **Conocimiento** del agente.

    ---

    ### **Recopilar Información**
    - **Descripción:** Permite al agente recopilar, verificar y almacenar información del usuario (por ejemplo, nombre, correo electrónico, número de teléfono) para generación de leads o solicitudes de servicio.
    - **Interruptor:** Desactivado por defecto.
    - **Configuración:** Define los campos que deseas que el agente recopile y dónde se debe almacenar la información.

    <Note>
    Esta herramienta es **tan importante** que una vez habilitada, activa una **pestaña dedicada de Recopilar información** en la sección de Habilidades. Desde ahí, puedes crear, editar y gestionar las configuraciones de recopilación en detalle.
    </Note>

    <Accordion title="Cómo Configurar Recopilar Información">
    1. Ve a **Agente IA > Diseño > Habilidades > Recopilar Información**.
    2. Haz clic en **Nueva Configuración** para comenzar.
    3. Ingresa un **Nombre** para tu configuración (ej., `registro_interesados`).
    4. Agrega **Instrucciones Especiales** para guiar al agente sobre cómo recopilar la información.
    5. Agrega los campos que deseas recopilar, especificando nombre, tipo y reglas de validación.
    6. Asigna la configuración a uno o más **canales**.
    7. Haz clic en **Guardar** para activar.
    </Accordion>

    ---

    ### **Escalar a Humano**
    - **Descripción:** Permite al agente transferir la conversación a un agente humano cuando sea necesario.
    - **Interruptor:** Desactivado por defecto.
    - **Configuración:** Requiere una integración compatible (Freshchat o Zendesk) conectada.

  </Tab>

  <Tab title="Herramientas (Personalizadas)">
    La pestaña **Herramientas (Personalizadas)** te permite crear tus propias herramientas—llamadas **Skills**—que conectan tu agente de IA a APIs y servicios externos. Este es el **Constructor de Skills** (*Skill Builder*).

    Un skill personalizado define una solicitud HTTP que el agente puede ejecutar durante una conversación. Configuras la URL del endpoint, el método HTTP, los parámetros de entrada y el formato de respuesta esperado.

    ---

    ## Crear un Skill Personalizado

    1. Navega a **Agente IA > Diseño > Habilidades**.
    2. Cambia a la pestaña **Herramientas (Personalizadas)**.
    3. Haz clic en **Nuevo Skill** para abrir el Constructor de Skills.
    4. Completa los detalles: nombre, descripción, URL, método HTTP, parámetros y tipo de retorno.
    5. Haz clic en **Guardar** para que el skill esté disponible para tu agente.

    ---

    ## Constructor de Skills: Parámetros de Entrada

    Cada parámetro de entrada que agregas a un skill personalizado requiere:

    - **Nombre** — la clave del parámetro.
    - **Tipo** — el tipo de dato: `string`, `int`, `float`, `bool`, `list` u `object`.
    - **Origen** — de dónde viene el valor: `conversation`, `end_user`, `state`, `store`, `config`, `fixed` o `configuration` (para secretos como API keys).
    - **Ubicación** — dónde se coloca el parámetro en la solicitud HTTP.

    ### Ubicaciones de parámetros

    | Ubicación | Etiqueta | Descripción |
    |---|---|---|
    | **query** | Como extra en el enlace web | Se agrega como parámetro de consulta en la URL |
    | **path** | Dentro del enlace web | Llena un `{placeholder}` en la ruta de la URL |
    | **body** | En los datos del mensaje | Se envía en el cuerpo JSON de la solicitud |
    | **header** | En el encabezado | Se envía como encabezado HTTP personalizado (común para API keys) |
    | **header_auth_bearer** | Como token Bearer | Se envía como el encabezado `Authorization: Bearer <valor>` |

    <Tip>
      Usa **Como token Bearer** cuando la API externa espera un token OAuth o JWT en el encabezado estándar `Authorization`. Esto es especialmente útil cuando se combina con el origen **end_user** para reenviar tokens obtenidos mediante [Login Externo](/agent/es/login-externo), ya que esos tokens se almacenan cifrados y se descifran automáticamente antes de enviar la solicitud.
    </Tip>

    ---

    ## Tipos de Retorno

    Define qué forma de datos devuelve la API externa para que el agente pueda interpretarlos:

    | Tipo de retorno | Descripción |
    |---|---|
    | **dict** | Un conjunto de detalles (objeto JSON) del que el agente puede leer campos |
    | **list** | Una lista de elementos |
    | **number** | Un valor numérico único |
    | **str** | Una cadena de texto plano |

  </Tab>
